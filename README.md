# Creep Avoider

Creep Avoider is a small 2D survival game made with Godot and GDScript. It is based on Godot's [Your first 2D game](https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html) tutorial.

Move around the screen and avoid the incoming creeps for as long as possible. Your score increases every second you survive. Touching a creep ends the game.

## Controls

| Action | Key |
| --- | --- |
| Move up | Up arrow |
| Move down | Down arrow |
| Move left | Left arrow |
| Move right | Right arrow |
| Start or restart | Click **Start** |

## Features

- Randomly positioned and directed enemies
- Three animated enemy types: flying, swimming, and walking
- Animated player movement in four directions
- Survival-based score counter
- Game-over and restart flow
- Background music and collision sound effect
- Player movement constrained to the game window
